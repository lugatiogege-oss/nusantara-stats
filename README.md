Nusantara Stats — situs statistik nasional Indonesia: penduduk 281,6 juta jiwa, PDB Rp22.139 triliun, IPM 75,02. Data per 2024 dari BPS, dengan grafik SVG buatan tangan dan tabel provinsi yang bisa dicari dan diurutkan.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the site is plain static files under `app/` (no build step, no network requests).
